# XP Tracker

Персональний трекер дисципліни та дистрибуції. Дві незалежні лінії прогресу:
**Режим** (синій, щоденні галочки) і **Дистрибуція** (зелений, лічильники інпутів).

## Запуск

Без збірки. Дані зберігаються в localStorage браузера.

```bash
python3 -m http.server 8765 --directory .
```

Відкрити http://localhost:8765. На iPhone: Safari → Поділитись → На Початковий екран,
тоді працює як окремий застосунок.

Резервна копія: екран «Рік» → Дані → Експорт JSON.

## Файли

- `index.html` — оболонка і таб-бар
- `styles.css` — темна тема в стилі iOS
- `store.js` — модель даних, збереження, всі розрахунки (XP, тижні, ранги, воронка, просідання)
- `app.js` — екрани та дії

## Як рахується

- **День.** Режим: XP з 15. Дистрибуція: XP від денної норми наступного рангу з нормами
  (норма місяця ÷ днів у місяці, округлено вгору). До Grinder це 2 відео, 1 пост, 1 хук, відповіді.
- **Тиждень.** Відсоток від максимуму за 7 днів. Ціль 80%.
- **Місяць.** Рівень тільки по інпутах: Grinder 40/20/15, Operator 80/40/30, Chad 120/60/45.
- **Рік.** Ранг перераховується з усієї історії по завершених тижнях (понеділок–неділя).
  Два тижні поспіль нижче порогу рангу — мінус один щабель. Тиждень без активності — річний XP лінії мінус 2%.
- **Реєстрації на 1000 переглядів** беруться з тижневого розбору воронки. Тиждень належить
  місяцю, в якому його четвер.
- «Регулярність випуску відео» для Normie: 3+ відео щотижня 4 тижні поспіль.
- Позначка «протестовано» в Банку хуків додає +1 до сьогоднішнього лічильника хуків.

Пороги й норми — константи `RANKS`, `REGULAR_VIDEOS_PER_WEEK`, `DECAY_PER_IDLE_WEEK` у `store.js`.
